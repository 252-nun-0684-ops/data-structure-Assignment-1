## Brief Description of Each Task

**Task01:** Takes 10 integers, displays all elements and displays in reverse order.
**Task02:** Finds largest, smallest and second minimum values with their indices.
**Task03:** Calculates sum, average and counts elements greater than average.
**Task04:** Searches a number using linear search and shows all indices.
**Task05:** Inserts a new number at given index by shifting elements right.
**Task06:** Deletes element at given index by shifting elements left.
**Task08:** Sorts array in ascending order using Bubble Sort and also shows descending.
**Task09:** Finds duplicate values and shows how many times each occurs.
**Task10:** Merges two arrays into third array and finds largest in merged array.
**Task11:** Merges two sorted arrays into a sorted third array without using any sorting algorithm.
**Task01: _ O(n):**we traverse the array once for input and dispaly.Time grows linearly.

**Task02 - O(n):** One loop to find max/min, so linear time.
**Task03 - O(n):** Sum and average need one full scan.
**Task04 - O(n):** Linear search checks each element in worst case.
**Task05 - O(n):** Inserting requires shifting elements to the right.
**Task06 - O(n):** Deleting requires shifting elements to the left.
**Task08 - O(n^2):** Bubble Sort uses two nested loops.
**Task09 - O(n^2):** To find duplicates we compare each element with others.
**Task10 - O(n):** Merging two arrays and finding max is linear.
**Task11 - O(n+m):** Two-pointer merge technique, most efficient way to merge sorted arrays without extra sorting.
